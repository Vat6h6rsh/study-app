# DM UI integration · 26 November 2026

Implemented for the 28 November BCS ZC219 typed, 50-mark exam. No git commands or commits were made. The concurrent author's `src/data/dm/**` and `content/dm/**` remained read-only throughout this UI work. There were no new npm dependencies and no DM content errors found.

## Delivered

- Active DM subject, persisted selection, subject-aware deep links/history, mobile navigation and Learn notes.
- Dashboard with the professor's seven core groups and the reported Slot 1 Q1–Q5 practice route. Manifest-based loading discovers all 256 practice questions and five mocks, including 39 Slot 1 exercises and two Slot 1 papers.
- Truth tables: 44px T/F cycles, per-cell marking, column/all reveals, follow-up choices and internal table scrolling.
- Formulas: bounded safe arithmetic parser, explicit `*`, right-associative powers, correct unary-minus precedence, all stored test points and wrong-answer value comparisons.
- Numeric answers: exact integers through BigInt. Sets: tolerant outer braces/spacing/order while preserving nested labels and ordered pairs. Partitions: brace groups or plain lines, arbitrary class order, no repeated members. Properties and MCQs: labelled controls and exact marking.
- MST: weighted SVG, edge buttons/text entry, algorithm-aware next-step checks with ties, Prim start vertex, undo, running/final totals, original image toggles and professor-style numbered model steps.
- Proofs/derivations: saved typed drafts, monospace option, notation help, optional auto-checkpoints, locked submission, editorial self-marking rubrics and model solutions. A review checkbox permits finalising a zero/partial rubric without ticking failed steps. Checkpoints add no marks.
- Timed mocks: per-paper budgets (150-minute fallback), persisted answers/deadlines, neutral running editors, automatic single submission after expiry, all auto marks plus self-assessed proof marks out of 50. Pending assessment is labelled provisional.
- Revealed practice parts earn zero; existing streak/confetti/error-shake feedback is reused with reduced-motion handling.
