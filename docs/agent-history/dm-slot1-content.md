## Slot 1 exam pattern (reported by students who sat it on an earlier date; shared openly in the course group)
5 questions, 50 marks:
- Q1 (10): (a) truth table of an implication-based expression, e.g. ((p -> q) -> r) -> s (4 variables, 16 rows) (5 marks); (b) mathematical induction: prove an expression is divisible by a number; reported: 7^(n+2) + 8^(2n+1) is divisible by 57 for all n >= 0 (5 marks).
- Q2 (10): (a) sets: union/intersection/difference/Cartesian product/properties (2 marks); (b) Hasse diagram of the divisibility poset on {1, 2, 3, 4, 6, 10, 12, 20, 30, 60} (divisors of 60 without 5 and 15): draw/describe it, find LUB, GLB, maximal and minimal elements (8 marks, about 2 each).
- Q3: equivalence relations and equivalence classes; reported flavour: colourings of a triangle's vertices with Red/Green/Blue considered equivalent under 120-degree rotations (find classes); plus classic checks (reflexive/symmetric/transitive, congruence mod n classes).
- Q4: recurrence relations; reported: a_n = 7a_(n-1) - 16a_(n-2) + 12a_(n-3) + n^4, a_0 = -2, a_1 = 0, a_2 = 5: find the characteristic equation r^3 - 7r^2 + 16r - 12 = 0 and its roots (2, 2, 3), a particular solution (degree-4 polynomial since 1 is not a root), and the general solution with constants from the initial conditions.
- Q5: graph theory: minimum spanning tree with Kruskal's algorithm (step-by-step: each edge added/rejected, total weight).


## IMPORTANT (student clarification about Q1b)
In the exam, the induction part required WRITING THE FULL PROOF, not just reaching an equation. The answer must be a complete typed proof: (1) statement P(n) and domain; (2) basis step with the computed value and why it is divisible (e.g. P(0): 7^2 + 8^1 = 57 = 57 x 1); (3) inductive hypothesis stated explicitly (assume 7^(k+2) + 8^(2k+1) = 57m for some integer m); (4) inductive step: start from P(k+1), rewrite it algebraically to expose the hypothesis, substitute, and show the result is 57 times an integer, naming that integer; (5) conclusion sentence citing the principle of mathematical induction. So for every induction question: use the `steps` type as the main answer with a rubric awarding marks for each of those five parts (e.g. 5 marks: statement+basis 1, hypothesis 1, algebraic manipulation 2, conclusion 1); checkpoints (like the basis value or the factor) are optional extras, never a substitute for the proof. Model proofs must be typed exactly as the student should write them, in full sentences plus the algebra lines. Apply the same "write the full proof" standard to the induction Learn note (03-induction.md): add a worked divisibility proof template and a list of common mark-losing mistakes (no hypothesis stated, assuming what is to be proved, not showing the factor, no conclusion).
