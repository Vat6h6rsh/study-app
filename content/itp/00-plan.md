# ITP: 2-day plan (exam 21 Nov 2026)

## Exam format (from group chat + instructor)
- Computer based. **5 questions × ~10 fill-in-the-blanks** in C programs. About 30 min per question.
- Partial marks per question (each blank all-or-nothing).
- **No theory, no flowcharts.**
- Weeks 5–9 matter most.

## What past papers actually test (5 papers, 2023–24): see question_bank.md
All of these appeared in 5/5 papers:
structs (+ typedef, array of structs, `->`) · 1D arrays (search/sort/merge) · 2D arrays (column sums, transpose) ·
strings (case toggling, indexing) · file handling · pointers (call by reference) · loops/digit algorithms.
Also: malloc/free (4/5), functions/recursion (4/5), operators/`++`/`--` output prediction (5/5).
