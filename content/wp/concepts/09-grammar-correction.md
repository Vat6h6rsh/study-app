# Q5B · Full paragraph correction

Topic ID: `grammar`

## Concept

Rewrite the entire paragraph in complete, grammatical sentences. Preserve meaning and highlight every correction. A list of errors alone does not satisfy the task.

## Why it matters

Errors interact. Changing a noun may require a new verb, article or pronoun. A full reread catches errors introduced during repair. Marking changes makes the correction visible.

## Step-by-step method

1. Read for meaning and identify the time frame.
2. Find each clause’s subject and finite verb. Ignore intervening of-phrases when checking agreement.
3. Scan tense consistency, articles, prepositions and pronoun reference.
4. Check word form, spelling, plurals and countability: carefully, not careful; information, not informations.
5. Repair run-ons and comma splices with a full stop, semicolon or comma plus conjunction. Join fragments to a main clause.
6. Highlight changed words and punctuation. For a deletion, highlight the repaired phrase. Reread the whole paragraph.

## Template / skeleton

```text
Agreement: Each response were → Each response ==was==.
Tense: Yesterday the team meet → Yesterday the team ==met==.
Articles: an useful guide → ==a== useful guide; a hour → ==an== hour.
Preposition: in Monday → ==on== Monday.
Pronoun: explained to they → explained to ==them==.
Run-on: The file failed we retried → The file failed==;== we retried.
Comma splice: The file failed, we retried → The file failed, ==so== we retried.
Fragment: Because the file failed. → Because the file failed, ==we retried==.
Word form: spoke polite → spoke ==politely==.
Spelling: recieve → ==receive==.
Plural: two device → two ==devices==.
```

Tip: Replace every placeholder with task-specific content.

## Worked exam-style prompt

The students was asked to complete a survey yesterday. Each response were checked careful by a librarian. The team discussed about the results and found that many student preferred a quiet room. A report was send to the manager, she promised to improve the signs.

## Fully worked model answer

The ==students were== asked to complete a survey yesterday. Each ==response was== ==checked carefully== by a librarian. The team ==discussed the results== and found that ==many students== preferred a quiet room. A report ==was sent== to the ==manager, who== promised to improve the signs.

## Why the model works

- students was → students were: A plural subject takes were.
- response were → response was: Each response is singular.
- checked careful → checked carefully: An adverb modifies checked.
- discussed about the results → discussed the results: Discuss takes a direct object.
- many student → many students: Many requires a plural count noun.
- was send → was sent: The passive needs a past participle.
- manager, she → manager, who: A relative clause repairs the comma splice.

## Common mistakes that lose marks

- Correcting only some errors or omitting a sentence.
- Changing the message to avoid difficult grammar.
- Highlighting the original error instead of its correction.
- Leaving a comma splice after fixing vocabulary.
- Treating singular they/their as automatically wrong. It is acceptable with an unknown-gender individual.
