# WP (BCS ZC239) exam-morning cheatsheet

Topic ID: `cheatsheet`

**Computer-based, typed. 50 marks, 5 questions, 9 parts. Assume 150 min (3 min per mark).** No citations. No article writing. Highlight = use the exam's own highlight/underline control; if it only has plain text, ask the invigilator and stay consistent (practice app uses `==word==`; `**bold**` or `__underline__` only if the interface supports it).

## 2. Q1A Argumentative essay (6 marks, 250 words, 17 min)

**Skeleton (words)**
| Section | Words | Fill-in |
|---|---|---|
| Intro | 35 | [Context]. [Who] should [position] because [reason 1] and [reason 2]. |
| Body 1 | 65 | First, [claim]. [How/why]. For example, [example]. [Link to thesis]. |
| Body 2 | 65 | Second, [different claim]. [Explain + example]. |
| Counter + rebuttal | 55 | Critics argue [fair objection]. This is valid where [condition]. However, [answer/safeguard]. |
| Conclusion | 30 | Therefore, [thesis again]. [Condition/final thought]. |

**Must do**
- Take a clear, definite (may be qualified) position in the first paragraph.
- Two DIFFERENT reasons, each with an example or mechanism.
- Counter-argument stated fairly, then rebutted.
- Conclusion restates the thesis; no new argument. Land at 240-260 words.

**Don't**
- Open with "Nowadays, X is important."
- Repeat the same reason twice; invent statistics.
- Write 400 words (or 150).

**Phrases**: [X] should ... because ... / First, ... / A further reason is ... / Critics argue that ... / This concern is valid, but ... / Therefore, ...

## 3. Q1B Paraphrase (4 marks, 11 min)

**Skeleton**: read twice, list the key points, look away, rewrite from your list, compare with the source.

| Technique | Example |
|---|---|
| Change structure | After checking the files, staff replied → Staff replied once the files were checked. |
| Change voice | The team analysed the files → The files were analysed by the team. |
| Change word form | The team decided → The team's decision |
| Reorder / split / combine | Move a clause to the front; split a long sentence |
| Synonyms in context | enable, respond, initiative, nevertheless |

**Must do**
- Keep ALL meaning: names, numbers, technical terms, conditions, strength of claims.
- Keep about the same length (it is not a summary).
- Change sentence structure, not just words. Check grammar.

**Don't**
- Swap two words and keep the same frame.
- Drop a negative, qualification or cause link (may help ≠ will solve).
- Add your opinion or new claims.

**Phrases**: [Cause] led to [effect] / [Effect] resulted from [cause] / Although [qualification], [claim] / Nevertheless, ... / [Procedure] was used to ...

## 4. Q2A Formal email (6 marks, 17 min)

**Skeleton**
```
Subject: [Action] - [specific matter / reference no.]
Dear [Name / Team],
I am writing to [purpose]. [One-line context.]
[Facts: dates, reference, defect, evidence available.]
Could you please [specific action] by [date]? 
Thank you for your assistance. I look forward to your reply.
Kind regards,
[Full name, role]
```
Types: complaint (item + defect + remedy) / enquiry (dates, fees, eligibility, steps) / request / follow-up (sent on [date], expected timetable?) / apology (accept responsibility + prevention).

**Must do**
- Specific subject line, greeting, sign-off with full name.
- Purpose in the FIRST sentence; then facts, then ONE clear request with a deadline.
- Polite, firm tone; say what evidence you can send (photos, receipt).
- Cover every detail the question lists.

**Don't**
- Slang, CAPITALS, "!!!", threats, blame, "do the needful".
- A long backstory before the purpose.
- Forget subject or signature.

**Phrases**: I am writing to request ... / The order reference is ... / Could you please confirm ...? / Please arrange a replacement/refund ... / I would appreciate a response by ... / I apologise for ... / Thank you for considering ...

## 5. Q2B Questionnaire (4 marks, 11 min; 1/2 mark each)

**Skeleton**: 1 line intro (purpose, voluntary) → **Open 1-4** → **Closed 5-8**. Number 1-8, label the groups, count to exactly 4 + 4.

| Type | Format / stem |
|---|---|
| Open (4) | What difficulties, if any, do you face with ...? / Describe an occasion when ... / How do you decide ...? / What change would improve ...? |
| Closed: Yes/No | Have you used [X] in the past week? Yes / No / Unsure |
| Closed: MCQ | Which device do you use most? Phone / Tablet / Laptop / Desktop / Other |
| Closed: Likert | How easy is [X]? Very easy / Easy / Neutral / Difficult / Very difficult |
| Closed: frequency | Days used last week? 0 / 1-2 / 3-4 / 5 or more |

**Must do**
- Exactly 4 open + 4 closed. Each closed question has options listed.
- Four different aspects of the topic. Neutral wording. Define a time frame.
- Open stems start with what / how / describe / why (not "Do you ...?").

**Don't** (examples)
- Leading: "Do you agree our excellent system helps?"
- Double-barrelled: "Is it cheap AND reliable?" (split it)
- Loaded: "Why do you waste time online?"
- Vague: "Do you use it often?" (no period or scale)
- 9 questions, or yes/no questions disguised as open.

## 6. Q3A Graph / table (5 marks, 14 min)

**Skeleton**
```
Overview: The [chart/table] shows [measure] for [categories/period] (unit). Overall, [main trend/biggest/smallest].
Evidence: [Highest/lowest] ... at [value]. A exceeded B by [diff]. 
Change: rose from [x] to [y], an increase of [diff] ([%]).
Close: [Answer to exactly what was asked.]
```

| Use | Vocabulary |
|---|---|
| Up/down | rose BY 20 (amount of change) / rose TO 100 (end value) / rose FROM 80 TO 100 / fell BY 10 / declined gradually |
| Peak/low | peaked AT 120 / reached a low of 40 / bottomed out AT ... |
| Stable | remained stable AT 50 / levelled off AT 50 |
| Variation | fluctuated BETWEEN 40 AND 60 |
| Compare | A exceeded B BY 15 / A was twice as high as B / In contrast, ... / accounted FOR 30% |
| Speed | sharply, steadily, slightly, gradually, dramatically |

**Must do**
- Read the QUESTION first (compare? trend? highest? difference?) and answer only that.
- Overview sentence first, then selected figures with units. Calculate differences carefully.
- Use "approximately" for estimated bar heights.

**Don't**
- Describe every number, or give reasons if not asked.
- Mix BY / TO. 40% to 50% = 10 percentage points (25% relative growth).
- Add opinion or outside facts.

## 7. Q3B Summary (5 marks, 14 min)

**Skeleton**
```
[Short specific TITLE]
[Main idea]. [Essential supporting point(s)]. [Qualification / outcome]. 
```
Target about half the passage length (unless a limit is given). One connected paragraph, own words. Highlight 3-5 keywords inside the summary (not the source, not the whole paragraph).

**Must do**
- Title + highlighted keywords (both are marked).
- Main idea first, then key points only. Own words.
- Check the length against the original.

**Don't**
- "I think...", recommendations or comments not in the passage.
- Examples, repetition, minor detail, copied sentences, fragments.

**Phrases**: The passage explains that ... / [Subject] involves ... / X is done to ... while Y ... / The aim is to ... / As a result, ...

## 8. Q4 Investigation report (10 marks, 28 min, ~350-450 words)

Style: impersonal ("the investigation found", not "I think"), past tense for method/findings, short paragraphs, use headings.

| Heading | Words | What goes in it |
|---|---|---|
| **Title** | - | Investigation into [specific situation] at [place] |
| **Abstract / Executive Summary** | 50 | Whole report in 4 sentences: purpose, method, main finding, main recommendation. WRITE LAST, place after title. |
| **Introduction** | 50 | Background, who requested it, purpose/aim, scope (what is and is not covered), period. |
| **Methodology** | 70 | HOW evidence was collected: who/what (sample size), where, when, tool, how analysed, one limitation. |
| **Findings** | 90 | WHAT was found: specific facts/numbers from the prompt, grouped by theme. No opinions or advice. |
| **Conclusion** | 50 | WHAT IT MEANS: interpretation justified by findings; cautious ("indicates"); no new facts. |
| **Recommendations** | 80 | WHAT TO DO: 3 numbered actions, each with owner + action + deadline + a review measure. |

**Example methodology**: "The investigation combined (a) a questionnaire completed by 30 students, (b) short interviews with two librarians and (c) direct observation on three weekday afternoons. Responses were grouped by recurring theme, and observation notes were checked against them. Participation was voluntary and anonymous. The small sample limits generalisation."

| | Example |
|---|---|
| **Finding** (fact) | 18 of 30 respondents reported disruption near the entrance. |
| **Conclusion** (meaning) | The current quiet-zone arrangements are insufficient. |
| **Recommendation** (action) | The manager should move the signs to eye level within two weeks and review complaints after four weeks. |

**Must do**
- All 7 headings, in order. Use EVERY fact supplied in the prompt; do not invent extra results.
- If no data is supplied, keep figures modest and label them as illustrative/assumed ("for this simulated investigation").
- Link: each recommendation answers a finding.

**Don't**
- Write a story/essay with no method. Put background only in the abstract.
- Overclaim ("all students agree") from a small sample. Put new findings in the conclusion.
- "Improve everything" (no owner/deadline).

**Phrases**: This report investigates ... / The review covered ... / Evidence was collected through ... / The findings indicate ... / Within this sample, ... / [Owner] should [action] by [date].

## 9. Q5A Abstract parts (4 marks, 11 min)

**Method**: read the 4 requested names first, then copy the exact sentence(s) from the abstract for each. Write the text, not a letter or label. Do not paraphrase, do not invent a missing part. One sentence may serve two parts (e.g. purpose + method).

| Part | Signal words |
|---|---|
| **Background** | Context/problem: "X is increasingly...", "Previous studies...", "Little is known about...", "However, ... remains unclear" |
| **Purpose / Aim / Statement of purpose** | "This study aims/aimed to...", "The purpose/objective was to...", "This paper examines/investigates/explores...", "We sought to determine whether..." |
| **Methodology** | "Data were collected...", "We surveyed/interviewed/analysed...", "A sample of N...", "using", "through", "participants", "experiment" |
| **Results / Findings** | "We found...", "The results showed/revealed...", numbers, percentages, "significantly higher" |
| **Conclusion / Implications** | "These findings suggest/indicate...", "We conclude...", "may support...", "further research is needed", "should" |

**Don't**: write "C" or a letter; call every later sentence "methodology"; mistake "we show" (a result) for an aim.

## 10. Q5B Grammar rewrite (6 marks, 17 min)

**Rewrite the WHOLE paragraph, every sentence, keeping the meaning. Mark each correction (the corrected word, not the error).** A list of errors is not enough. Mark changed punctuation too. For a deletion, mark the repaired phrase. Use ONE marking style throughout.

**Scan in this order (one pass per item, then reread the whole paragraph):**

| # | Check | Example fix |
|---|---|---|
| 1 | Subject-verb agreement (ignore of-phrases) | Each response were → was |
| 2 | Tense consistency / time words | Yesterday the team meet → met |
| 3 | Articles a/an/the/none | an useful guide → a useful; a hour → an hour |
| 4 | Prepositions | in Monday → on; discussed about → discussed |
| 5 | Pronoun case/reference | explained to they → them |
| 6 | Plural / countable | many student → students; informations → information |
| 7 | Word form (adj/adv/noun) | checked careful → carefully |
| 8 | Verb forms / passive participle | was send → sent; has went → gone |
| 9 | Run-on / comma splice | failed, we retried → failed, so we retried |
| 10 | Fragments | Because the file failed. → add a main clause |
| 11 | Spelling and confused words | recieve → receive; their/there; affect/effect |
| 12 | Capitals, apostrophes, commas | students book → student's book |

**Don't**: fix only some errors; skip a sentence; change the meaning; highlight the old error; leave a comma splice; correct "they/their" for a singular unknown-gender person (acceptable).
